# Agent guide

## Purpose

Help QHPC members prepare for meetings with short shared guides and apply their
learning through meeting activities.

[CONTRIBUTING.md](CONTRIBUTING.md) is the source of truth for content standards,
repository layout, prerequisites, resources, and checks. Follow it rather than
duplicating those rules here.

## Workflow

Read README.md, CONTRIBUTING.md, and the affected meeting or shared guide before
editing. Check `git status --short` and review staged, unstaged, and new files.
Preserve manual edits, screenshots, and existing staging; do not restage or discard
the user's work while making a targeted change.

- Make focused changes within the requested scope.
- Agents can draft and check files locally; team members handle CAC execution.
  Run examples only within the task's scope; never claim a run that did not happen.
- Do not merge, publish, or push without task authorization.
- Change content standards in CONTRIBUTING.md and keep the meeting template aligned.
  Update this file when agent responsibilities change.

## Checks and handoff

Run the [repository checks](CONTRIBUTING.md#check-and-submit), inspect untracked
files, and review the affected Markdown and links. Report checks and execution
limits briefly, including platforms or CAC steps that were not run.
